# 桃源谷的玩法与保存

从遗迹返程引开追兵后，在原桃源谷与万薇莉相识。首次对白完成即可沿原场景探索；原摇杆/A/D移动，走近地点点击“参与活动”，使用原技能按钮“行动 E”。

- 鱼塘（3400）：靠近浮出水面的鱼，时机合适时捞鱼，收取三条。
- 田间（4700）：靠近三道田垄，依次播种、浇水、等待生长并收获。
- 桃林（6100）：在三棵树旁驻足观赏，再记录风景。
- 鸡舍（7800）：追上两只野鸡，靠近后收拢入栏。
- 静听处（9300）：停步三秒，选择怪物话语的意思，答错需要重新静心。

活动可选，完成各自任务获得一次奖励；中途进度写入独立桃源表。奖励写入失败时保留待提交的动作结果，点击“重试保存”，无需重复动作。新版存档版本不兼容时拒绝写入。

学会怪物语后回吊床附近选择“练习几日，再会朋友”；休息后走近万薇莉，与怪物交流并听大狐狸的来历。首次演出包含完整休息/苏醒动作与原狐狸进场。通讯第11页可重读后两段，重读不重演、不重复奖励。

具体数值、地点与奖励物品为原2-12五项活动的实现细化。原原稿保留32句初见和24句后续对白。鱼、作物、桃树、鸡舍及野鸡为新增原生矢量表现，万薇莉/友善小怪/大狐狸及谷地均使用原资产。
