## 制作顺序

1. 恢复参考工程的图片路径和图集附件，验证导出后原作模型在引擎中保持动作与网格形变。
2. 对照原 Q 稿确定头身、肩肘腕、髋膝踝、前后遮挡。重新准备可蒙皮分层；保留关节覆盖和被遮挡部分，排除生成图集里的虚假关节圆点。
3. 建立九尾狐自己的 setup pose 和加权网格。选择可适配的原作行走/待机骨骼控制曲线，按比例转移，保留其缓入缓出、重心、身体与头部反向补偿。
4. 头发、侧后蝴蝶结、衣摆使用连续骨链与网格权重；面部表情单独制作，不能靠整张头部重生成替换。
5. 只先做 idle 与 fmove 样片。原稿、九尾狐、原作 Q 角色在相同显示高度、实际移动速度和地面下并排播放。视觉合格后才继续 prepare、转身、剧情动作和正式接入。

首选正式 Spine 绑定与针对角色的关键帧制作。原作曲线用于学习节奏和重心，不能直接替代动画师对狐狸比例及性格的设计。必要时需要补画关节覆盖、侧面手脚和表情附件。
